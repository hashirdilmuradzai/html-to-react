# HTML to React

A frontend assignment focused on recreating an HTML-based webpage using React. This project demonstrates how to convert traditional HTML elements into JSX and build a structured webpage with React.

## 🚀 Features

- Natural wonders information
- Headings and descriptions
- Ordered lists
- Image integration
- Country details
- Clean and structured layout
- React-based UI

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- JSX
- HTML5
- CSS3

## 📚 Concepts Practiced

- React Components
- JSX Syntax
- Rendering Elements
- JavaScript Arrays
- HTML to JSX Conversion
- Image Handling
- CSS Styling
- Component-Based Development

## 🎯 Assignment Objective

To recreate an HTML webpage using React and understand how HTML elements are converted into JSX while practicing React fundamentals and component-based development.
